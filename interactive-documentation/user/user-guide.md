## Как устроена работа

Все задачи принадлежат **пользователю**. Поэтому сначала создаётся пользователь, а затем от его имени ведутся задачи.

## Операции

### Создать пользователя

1. Откройте приложение.
2. Введите имя в поле пользователя.
3. Нажмите **«Создать пользователя»**.

### Создать задачу

1. Выберите своего пользователя.
2. Введите **название** (обязательно) и, при желании, описание.
3. Нажмите **«Добавить»**.

Задача получает статус «Новая» и дату создания.

### Изменить статус задачи

1. Найдите задачу в списке.
2. Выберите новый статус.

| Статус | Значение | Дата закрытия |
|---|---|---|
| Новая | Задача создана | не задана |
| В работе | Задача выполняется | не задана |
| Выполнена | Задача завершена | фиксируется автоматически |

### Удалить задачу

1. Найдите задачу в списке.
2. Нажмите **«Удалить»** и подтвердите действие.

> **Внимание:** удалённую задачу восстановить нельзя. Восстановление возможно только администратором из резервной копии.

## Советы

- Давайте задачам короткие понятные названия.
- Закрывайте выполненные задачи сразу — так дата закрытия будет точной.
