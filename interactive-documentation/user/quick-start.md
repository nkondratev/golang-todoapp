# Быстрый старт

**Разделы:** [Главная](../index.md) | Пользователю: [Быстрый старт](../user/quick-start.md) · [Руководство](../user/user-guide.md) · [FAQ](../user/faq.md) | Разработчику: [Установка](../developer/installation.md) · [Архитектура](../developer/architecture.md) · [API](../developer/api-reference.md)

Цель раздела — за несколько минут создать пользователя и первую задачу. Предполагается, что администратор уже установил приложение и сообщил вам его адрес (подробности — в [установке](../developer/installation.md)).

## Что понадобится

- современный браузер;
- адрес приложения от администратора (например, `http://localhost:8080`);
- доступ к серверу по локальной сети.

## Шаги

1. Откройте адрес приложения в браузере.
2. Создайте пользователя: введите имя и нажмите **«Создать пользователя»**.
3. Введите название задачи в форме создания.
4. Нажмите **«Добавить»** — задача появится в списке со статусом «Новая».
5. Когда задача выполнена, измените её статус на «Выполнена».

![Интерфейс приложения: форма создания и список задач](../images/interface.svg)

## Результат

В списке отображается ваша задача с датой создания. После закрытия появится и дата закрытия.
