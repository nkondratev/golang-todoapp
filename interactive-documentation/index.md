# Задачи онлайн

Веб-приложение для ведения списка задач: пользователь создаёт учётную запись, добавляет задачи, меняет их статус и удаляет ненужные. Система сохраняет дату создания и дату закрытия каждой задачи.

**Разделы:**
[Главная](index.md)
[Пользователю](user/quick-start.md)
[Разработчику](developer/installation.md)

## Назначение

Документация помогает:

- **пользователю** — быстро начать работу и выполнять основные операции с задачами;
- **разработчику и администратору** — развернуть приложение в Docker, понять его архитектуру, пользоваться API, делать резервные копии и откат.

## Основные возможности

- создание пользователя, от имени которого ведутся задачи;
- создание, просмотр, изменение статуса и удаление задач;
- учёт даты создания и даты закрытия задачи;
- REST API с описанием в Swagger;
- запуск одной командой через Docker Compose;
- автоматическое резервное копирование базы данных каждый час.
